# 🇺🇸 English A2 Bot — Special FOR Ksen4ik 💖
Telegram-бот для изучения **американского английского** (уровень A2).
Хостинг: **Render (Free)** · хранилище: **Google Sheets** · cron-job.org нужен только для «Слова дня».

## Что умеет
| Раздел | Что внутри |
|---|---|
| 🆕 Слова | ~990 слов в 29 темах (американская лексика и написание: *apartment, check, vacation, fall…*), примеры, озвучка с американским произношением. Темы Travel расширены до трёх подтем (аэропорт, транспорт, город и туризм), добавлена тема «🏨 Отель» из словаря пользователя |

| 📘 Глаголы | 100 неправильных глаголов из PDF пользователя в 10 группах: таблицы V1–V2–V3 с транскрипцией, **предложения с V2 и переводом**, **упражнение «русский глагол → назови все три формы по-английски»** (V1–V2–V3, с подсказкой), тренировка в обе стороны (EN→RU, RU→EN), выбор формы V2 (с ловушками V1/V3) и вставка пропущенной формы; свой прогресс по каждому глаголу |

## 🛠 Админ-раздел (только для `ADMIN_ID`)
Кнопка «🛠 Админ» появляется в меню у админа, либо команда `/admin`.
- **📊 Статистика** — уровень, XP, серия, цель дня, точность, выучено слов/глаголов, когда занималась в последний раз.
- **👤 Карточка ученика** — подробно: график за неделю, сложные слова, значки, настройки, темы.
- **🎯 Управление обучением** — цель дня, слов за раз, «слово дня» (вкл/выкл, час), темы слов, «всё на повтор сегодня», подарки (+50 XP, +1 заморозка серии; она получает уведомление). Команда `/assign слово - перевод` добавляет слово в её квиз.
- **⏰ Напоминания** — «отправить сейчас», 4 готовых фразы, свой текст (`/remind текст`), ежедневное напоминание по расписанию (час и текст `/remtext текст`; приходит, только если в этот день она ещё не занималась). Для расписания нужна задача cron-job.org на `/cron/tick` около выбранного часа (например, каждый час с 12 до 22).
- **📨 Сообщения** — `/msg текст` всем ученикам. **💌 Записки** — `/notes`, `/note`, `/delnote N`.
- **📬 Дайджест** — вечером (после 21:00 по твоему часовому поясу) бот присылает сводку дня по ученикам.
- `/diag` — проверка переводчиков.

## Установка

### 1. Бот в Telegram
@BotFather → `/newbot` → токен (`BOT_TOKEN`). Telegram ID (свой и жены) — у @userinfobot.

### 2. Google Sheets
1. Создай **новую** таблицу, возьми её ID из адреса: `docs.google.com/spreadsheets/d/<SHEET_ID>/edit`.
2. [console.cloud.google.com](https://console.cloud.google.com) → проект → *APIs & Services → Library* → включи **Google Sheets API**.
3. *IAM & Admin → Service Accounts* → создай аккаунт → *Keys → Add key → JSON*.
4. В таблице «Настройки доступа» → добавь e-mail сервисного аккаунта (`…@…iam.gserviceaccount.com`) как **Редактор**.
5. Содержимое JSON одной строкой — в переменную `GOOGLE_CREDS_JSON`.

Вкладки `users`, `words`, `verbs`, `notes` бот создаёт сам. Если таблица осталась от прошлой версии бота — ничего делать не надо, новые столбцы добавятся автоматически.

### 3. Render
1. Залей **все файлы** проекта в репозиторий GitHub (замени старые; `.env` не заливай).
2. Render → *New + → Blueprint* (подхватит `render.yaml`) или Web Service вручную: Build `pip install -r requirements.txt`, Start `python main.py`, Free, Health Check `/health`.
3. Переменные:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен BotFather |
| `WEBHOOK_SECRET` | любая случайная строка |
| `CRON_KEY` | другая случайная строка (защита `/cron/tick`) |
| `GOOGLE_CREDS_JSON` | JSON сервисного аккаунта одной строкой |
| `SHEET_ID` | ID таблицы |
| `ALLOWED_IDS` | Telegram ID жены и твой через запятую |
| `ADMIN_ID` | твой Telegram ID (`/note`, `/msg`, подробные ошибки перевода) |
| `DEFAULT_TZ` | например `Europe/Berlin` |
| `GAS_URL`, `GAS_KEY` | **самое надёжное для перевода**: свой бесплатный переводчик на Google Apps Script (инструкция в файле `google_translate_proxy.gs`: 5 минут, без карты) |
| `MYMEMORY_EMAIL` | **рекомендую**: любой настоящий e-mail. Без него общий IP Render часто упирается в лимит переводчика (ошибка 429), с ним — 50 000 символов в день только твои |

Проверка: `https://<сервис>.onrender.com/health` → `ok`.

### 4. Cron — только если включено «Слово дня»
Если «Слово дня» не нужно, cron-job.org вообще не нужен, а сервис просыпается только от сообщений (экономит бесплатные часы Render).
Иначе: cron-job.org → задача `GET https://<сервис>.onrender.com/cron/tick?key=<CRON_KEY>` раз в день в час «слова дня» (+ повтор при ошибке).

## Как обновить уже работающего бота
Замени файлы в репозитории GitHub новыми (весь архив) → Render сам задеплоит. Данные в Google-таблице сохранятся.

## Если перевод не работает
Команда `/diag` (только для админа) проверяет каждый переводчик отдельно и показывает, кто отвечает с твоего сервера.

Бот опрашивает сразу несколько переводчиков (Google, MyMemory и зеркала Lingva) и берёт первый ответ; готовые переводы кэшируются. Самая частая причина сбоев — ошибка 429 «слишком много запросов» от общего IP Render: добавь `MYMEMORY_EMAIL`. В логах Render ищи строки `all translators failed` — видно, что ответил каждый сервис. Администратор (`ADMIN_ID`) видит причину прямо в чате. Слова из встроенных списков переводятся и без интернета.

## Свои слова и фразы
- `words*.txt`: `english|перевод|пример|транскрипция`, строки `# Тема` — новые темы
- `slang.txt`: `slang|перевод|пример|пометка`
- `phrases*.txt`: `русская фраза|вариант1/вариант2`, строки `# Категория`
- `verbs.json` — неправильные глаголы (собран из PDF)
