# 🇺🇸 English A2+ → B1 Bot — Special FOR Ksen4ik 💖
Telegram-бот для изучения американского английского. Хостинг: **Render (Free)** · хранилище: **Google Sheets**.

## Что умеет
| Раздел | Что внутри |
|---|---|
| 🆕 Новые слова | `/new` — **6 слов за раз: 2 существительных, 2 глагола, 2 прилагательных**. У каждого: перевод, часть речи, пример и **примечание, где слово употребляют** («о еде», «о людях», «сленг: к другу»…). Остальные части речи входят в эти 3 группы по происхождению: местоимения, предлоги и союзы — к существительным, фразовые глаголы — к глаголам, причастия и наречия от прилагательных — к прилагательным. ~1200 слов (A2, A2+ и B1), сленг есть в каждой группе, отдельного списка сленга нет |
| 🧠 Квиз | повторение слов с интервалами (метод Лейтнера): перевод выбираем из 4 вариантов, в обе стороны |
| 📘 Глаголы | `/verbs` — 100 неправильных глаголов в 10 группах: таблицы V1–V2–V3, предложения с V2 и переводом, тренировка (EN↔RU, выбор формы, вставка слова, «русский → 3 формы») |
| 📐 Грамматика | `/grammar` — 4 времени: Present Simple, Present Continuous, Past Simple, Past Continuous (теория + 8 упражнений на каждое) |
| 📚 Мои слова | `/words`, `/add`, `/del`, `/hard` (слова с ошибками, повтор по кнопке) |
| 💬 Перевод | любое слово или фразу можно просто написать боту: сначала поиск в своём словаре (мгновенно), потом онлайн-переводчики; форма неправильного глагола покажет все три формы |
| ⚙️ Настройки | «Слово дня» (6 слов по утрам, по желанию) и часовой пояс `/tz` |
Рейтинга, очков, уровней и серий в боте нет. Кнопка «🏠 Главное меню» есть под каждым сообщением.

## 🛠 Админ-раздел (только для `ADMIN_ID`)
Кнопка «🛠 Админ» или `/admin`:
- **Статистика и карточка ученика**: слов в словаре и выучено, глаголов выучено, точность, ответов сегодня, когда занималась, график за неделю, сложные слова.
- **Управление обучением**: «слово дня» (вкл/выкл, час), «прислать 6 слов сейчас», «всё на повтор сегодня»; `/assign слово - перевод` — слово ей в квиз.
- **Напоминания**: отправить сейчас, 4 готовые фразы, свой текст (`/remind`), ежедневное напоминание по расписанию (`/remtext`; приходит, только если она в этот день не занималась). Для расписания нужна задача cron-job.org на `/cron/tick` около выбранного часа.
- **Сообщения и записки**: `/msg`, `/note`, `/notes`, `/delnote N`. **Дайджест**: вечером сводка дня.
- `/diag` — проверка переводчиков.

## Установка
1. **Бот**: @BotFather → `/newbot` → токен. Telegram ID — у @userinfobot.
2. **Google Sheets**: новая таблица, включить Google Sheets API в Cloud Console, сервисный аккаунт → ключ JSON → дать аккаунту доступ «Редактор» к таблице. Вкладки бот создаёт сам; старые данные подхватываются.
3. **Render**: залей все файлы в GitHub → New Blueprint (`render.yaml`) или Web Service: Build `pip install -r requirements.txt`, Start `python main.py`, Free, Health Check `/health`.
4. **Переменные**: `BOT_TOKEN`, `WEBHOOK_SECRET`, `CRON_KEY` (любые случайные строки), `GOOGLE_CREDS_JSON` (JSON одной строкой), `SHEET_ID`, `ALLOWED_IDS` (ID жены и твой), `ADMIN_ID`, `DEFAULT_TZ`, рекомендуется `GAS_URL` + `GAS_KEY` (свой бесплатный переводчик на Google Apps Script, инструкция в `google_translate_proxy.gs`) и `MYMEMORY_EMAIL`.
5. **cron-job.org** нужен только для «слова дня», напоминаний по расписанию и дайджеста: `GET https://<сервис>.onrender.com/cron/tick?key=<CRON_KEY>`.

## Свои слова
`lexicon_a2.txt` и `lexicon_b1.txt`: `english|часть речи|перевод|пример|примечание|уровень`, разделы `# N` (существительные), `# V` (глаголы), `# A` (прилагательные).
Грамматика — `grammar.txt`, неправильные глаголы — `verbs.json`.

## Если перевод не работает
Бот опрашивает несколько переводчиков одновременно. `/diag` покажет, какие отвечают с твоего сервера; самое надёжное — свой `GAS_URL`.
