# 🇬🇧 English A2 Bot — Special FOR Ksen4ik 💖
Telegram-бот для изучения английского

Бесплатный хостинг: **Render (Free)** · хранилище: **Google Sheets** · расписание: **cron-job.org**

## Что умеет
- 🆕 «Слова дня» с примерами и озвучкой (9 тем, 108 слов) — приходят сами в выбранное время
- 🧠 Квиз с интервальным повторением (метод Лейтнера): чем лучше знаешь слово, тем реже оно появляется
- ✍️ Перевод фраз RU→EN с проверкой (прощает мелкие опечатки)
- 💬 Любое слово/фразу можно просто написать — бот переведёт, озвучит и предложит добавить в словарь
- 📚 Личный словарь (`/add`, `/del`, `/words`), 🔥 серия дней, XP и уровни, 📊 статистика
- ⚙️ Настройки: темы, слов в день, время, вечернее напоминание, часовой пояс
- 💌 Для мужа: `/note текст` — копилка тёплых записок (бот иногда добавляет их к «слову дня»), `/msg текст` — мгновенное сообщение жене

## Как это работает на бесплатном Render
Бесплатный сервис Render «засыпает» через 15 минут без запросов и просыпается за 30–60 секунд. Поэтому:
- бот работает через **webhook**: любое сообщение будит сервис само (первый ответ после паузы может прийти с задержкой до минуты);
- рассылку («слово дня», напоминание) запускает внешний **cron-job.org**, который раз в нужное время дёргает адрес `/cron/tick`;
- данные хранятся в **Google Sheets** (у Render на бесплатном тарифе диск не сохраняется).

## Установка

### 1. Бот в Telegram
@BotFather → `/newbot` → скопируй токен (`BOT_TOKEN`). Свой и женин Telegram ID узнай у @userinfobot.

### 2. Google Sheets
1. Создай **новую** таблицу (лучше отдельную, чтобы не смешивать с другими данными). Из её адреса возьми ID: `docs.google.com/spreadsheets/d/<ЭТО_SHEET_ID>/edit`.
2. [console.cloud.google.com](https://console.cloud.google.com) → создай проект (или используй существующий) → *APIs & Services → Library* → включи **Google Sheets API**.
3. *IAM & Admin → Service Accounts → Create* → открой аккаунт → *Keys → Add key → JSON* — скачается файл.
   (Если для другого бота на Render такой аккаунт уже есть — можно использовать его же.)
4. В таблице нажми **«Настройки доступа»** и дай доступ **Редактор** адресу сервисного аккаунта (`...@...iam.gserviceaccount.com`, он указан в JSON).
5. Содержимое JSON-файла целиком понадобится как переменная `GOOGLE_CREDS_JSON`.

Вкладки `users`, `words`, `notes` бот создаст сам. Во вкладке `notes` можно вручную писать записки для жены (по одной в строке под заголовком `text`).

### 3. Render
1. Залей папку проекта в **новый репозиторий GitHub** (файл `.env` не заливай — он в `.gitignore`).
2. Render → *New + → Blueprint* → выбери репозиторий (подхватится `render.yaml`) **или** *New + → Web Service* вручную:
   Build: `pip install -r requirements.txt`, Start: `python main.py`, Instance type: **Free**, Health Check Path: `/health`.
3. Переменные окружения (Environment):

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `WEBHOOK_SECRET` | любая случайная строка (буквы, цифры, `_`, `-`) |
| `CRON_KEY` | другая случайная строка — защищает адрес рассылки |
| `GOOGLE_CREDS_JSON` | весь JSON сервисного аккаунта |
| `SHEET_ID` | ID таблицы |
| `ALLOWED_IDS` | Telegram ID жены и твой через запятую — остальным бот не отвечает |
| `ADMIN_ID` | твой Telegram ID (для `/note` и `/msg`) |
| `DEFAULT_TZ` | часовой пояс по умолчанию, напр. `Europe/Berlin` |
| `REMIND_HOUR` | (необязательно) час вечернего напоминания, по умолчанию 20 |

Webhook бот ставит сам (адрес берёт из `RENDER_EXTERNAL_URL`). Проверь: `https://<твой-сервис>.onrender.com/health` → `ok`.

### 4. Расписание (cron-job.org, бесплатно)
Зарегистрируйся на cron-job.org и создай задачу:
- URL: `https://<твой-сервис>.onrender.com/cron/tick?key=<CRON_KEY>`
- Расписание: смотри ниже. В настройках задачи включи повтор при ошибке (retry): если сервис спал, первый запрос может не успеть.

**Выбери вариант по часам.** У Render на бесплатном тарифе 750 часов в месяц на весь аккаунт, и сервис «просыпается» от каждого запроса:
- 🅰️ **Экономный** (рекомендую, если уже есть другой бесплатный сервис): 2 задачи — в час «слова дня» (например 09:00) и в 20:00. Сервис бодрствует считанные минуты в сутки.
- 🅱️ **Точный по минутам**: каждые 10 минут с 08:00 до 22:00 — около 420 часов в месяц; вместе с другим всегда-включённым сервисом можно упереться в лимит 750.

Рассылка «догоняющая»: если запрос пришёл позже назначенного часа, слово дня всё равно придёт один раз за день.

### 5. Проверка
Открой бота → `/start` → выбери темы → получи первый урок. Дальше проверь `/quiz`, `/phrase`, `/stats`, `/settings`.
Время и часовой пояс жена настраивает сама (`/settings`, `/tz Europe/Moscow`).

## Локальный запуск (для проверки)
```
pip install -r requirements.txt
set BOT_TOKEN=...        (Windows)   |   export BOT_TOKEN=...   (Mac/Linux)
set USE_POLLING=1                    |   export USE_POLLING=1
python main.py
```
Без `GOOGLE_CREDS_JSON` данные пишутся в локальный `data.json`.

## Свои слова и фразы
- `words.txt` — строки вида `english|перевод|пример`; строки `# Тема` — новые темы.
- `phrases.txt` — `русская фраза|вариант1/вариант2`.

## Если что-то не так
- Бот молчит: проверь `/health`, логи в Render, `ALLOWED_IDS` и что `WEBHOOK_SECRET` без пробелов/спецсимволов.
- `APIError 403` / `PERMISSION_DENIED`: таблица не расшарена на сервисный аккаунт.
- Не приходит «слово дня»: открой адрес `/cron/tick?key=...` в браузере — должен вернуться JSON с числами; проверь `/tz`.
- Озвучка и перевод используют бесплатные сервисы Google (gTTS, deep-translator): иногда они недоступны — просто повтори позже.
